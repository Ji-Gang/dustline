# DUSTLINE 0.4 / 铸造工坊 · 2v2 联机

## 开始游戏

双击 游戏快捷方式，或 dist/DUSTLINE-win32-x64/DUSTLINE.exe。新版默认进入真人联机模式，四人到齐后由房主开始。没有 AI 补位。请保留整个 DUSTLINE-win32-x64 文件夹，不要只发送 exe。

1. 四位玩家使用同一版本软件。
2. 一人选择“创建房间”，设置获胜击杀数、重生保护、重生等待与端口。
3. 房间内会显示房间码及房主的局域网地址。把其中能与好友互通的地址及六位房间码告诉其余三人。
4. 其余三人填写名字、房主地址（如 192.168.1.8:27888）和房间码，点击“加入房间”。每队两人，房间内可以换队。
5. 房主点击“开始 2 vs 2 对战”。在出生区选好枪，点击“装备就绪”即可行动。

同一局域网可直接加入；Windows 若提示防火墙访问，需允许游戏在使用的网络上接收连接。异地需双方可互通的虚拟局域网，或房主配置路由器 TCP 端口映射。默认 TCP 27888，可自行修改。本版不包含公网匹配服务、自动穿透或中继服务器，不是仅凭房间码就能跨网络连接。

## 对局规则

- 每队最多 2 名真人，总共 4 人；双方人数齐全后开始。
- 团队击杀达到房主设置的目标即获胜，范围 1–200，默认 30。对局结束后房主返回房间，可以调整设置再战。
- 重生等待 1–10 秒，默认 3 秒；保护 1–10 秒，默认 4 秒。无敌倒计时及人物脚边光环会显示保护状态。开火立即解除自己的保护。
- 每次重生恢复生命和弹药，保留上一把枪，并自动打开装备库。16 种武器免费选择。
- 只要本次生命没有离开过自己的出生区，就能按 B 重新选枪；越过黄色出生线即锁定，返回出生区也不能再次选枪，下一次重生才恢复资格。
- 阵亡后可观看存活队友，倒计时结束后自动重生。
- 不造成友军伤害；障碍物遮挡弹道，枪械保留后坐力、散布、不同射速、换弹和有限备用弹药。
- Esc 打开菜单只暂停你自己的操作，联机世界继续运行。切出窗口会停止移动和射击。
- 有人中途离开时，当前比赛回到房间，补齐人数后重新开始；房主关闭软件或离开其创建的房间，会断开整个房间。

地图为原创“铸造工坊”，约 80 × 60 米，对称出生区、三条路线、中央发电设备与侧翼货运掩体。模型包含金属板接缝、螺钉、通风百叶、管道、屋顶桁架、储物柜和集装箱波纹；使用清晰材质、动态阴影与细致枪械模型。当前为程序化建模，并非扫描级商业资产。

## 验证和项目结构

- pvp/arena.js：客户端与服务器共用的地图、碰撞和移动。
- pvp/match.cjs：由服务器决定移动、命中、伤害、分数、出生、保护与选枪资格。
- pvp/server.cjs：TCP 房间、房间码、协议版本、人数限制与断线清理。
- pvp/client.js / pvp/index.html / pvp/pvp.css：房间、对战、装备库、局部移动预测与其他玩家插值。
- pvp/art.js：工业场景几何细节。
- desktop/preload.cjs / desktop/network.cjs：隔离的桌面通信接口，网页无 Node.js 权限。
- desktop/main.cjs / desktop/build.cjs：软件入口与便携版打包。
- pvp/test.cjs：规则回归和四个真实 TCP 连接测试。
- desktop/verify-pvp.cjs：打包文件的桌面 WebGL、IPC、武器与移动同步、重生装备库检查。

已通过 13 项联机检查（包含四连接测试）、36 项原有功能回归，以及真实桌面渲染与联机接口检查。还未做四台实体电脑或公网延迟环境下的长期对战测试。

开发：npm install；node node_modules/electron/install.js；npm test；npm run build。无需第三方云服务或网络库。当前服务器以 30 Hz 模拟、15 Hz 推送状态，使用 TCP；面向好友房间和局域网玩法。

之前的单机版本源文件仍保留；index.html 可打开旧单机网页，说明见 README-offline.md。Windows 快捷方式启动的是新版联机游戏。
