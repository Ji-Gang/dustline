# DUSTLINE / 沙城行动

离线三维战术 FPS：5 对 5 AI 爆破、双包点地图、回合经济、16 种武器和 5 档敌方难度。先赢五回合获胜。

## Windows 软件版

双击 dist/DUSTLINE-win32-x64/DUSTLINE.exe，游戏会在独立窗口运行，无需打开浏览器、联网或安装 Node.js。请保留整个 DUSTLINE-win32-x64 文件夹，不要单独移动 exe。F11 或 Alt+Enter 切换全屏，Esc 暂停。桌面版沿用当前 Three.js 游戏内容，通过 Electron 自带运行环境运行。

右键按住瞄准，Q 键也可切换瞄准。游戏窗口全局阻止页面右键菜单，失去焦点或暂停时自动退出瞄准，避免卡住。

开发与重新打包：npm install，node node_modules/electron/install.js，npm test，npm run build。Electron 版本固定于 package-lock.json。

## 网页备用启动

双击本目录的 index.html，用桌面版 Edge、Chrome 或 Firefox 打开。先选择敌方 AI 难度，点击“进入装备室”，选购武器，再点击“开始本回合”。本地已包含渲染库、模型和音效生成代码，无需联网或安装依赖。

浏览器需要启用图形加速及 WebGL。请保留整个目录。点击游戏画面捕获鼠标；Esc 释放鼠标并暂停。锁定失败时可按住左键拖动视角，或用方向键转向。

## Dust II 地图升级

- 地图扩大至约 164 × 156 米，重建 A 大道、A 大门、A 小道、中门、B 洞和 CT 转点通道。A 点高台与猫道高 3 米，阶梯、斜坡可通行，隧道顶棚遮挡子弹和视线。
- 增加石块接缝、墙面斑驳、百叶窗、阳台栏杆、拱门、木门铆钉和门环、屋顶空调与天线、车辆轮毂和内饰、油桶、脚手架、线缆和包点地标。静态模型按空间分区合并。
- 进攻方为玩家加四名队友，防守方五人；两队分别集中出生于 T 区、CT 区，每回合恢复出生队形。AI 按大道、小道、隧道和中路分路推进或布防。
- 玩家及 AI 基础移动速度提高 42%，保留静步、蹲伏、瞄准及不同武器的速度差异。
- 死亡观战跟随存活队友的高度、蹲姿与瞄准方向，隐藏被观战者自身模型防止头部挡住画面；显示队友枪械、生命和弹药。支持左右方向键、鼠标左右键、滚轮或观战按钮切换。队友阵亡自动换人，全部阵亡则等待回合结果。

## 枪械与 AI

- 敌方 AI 增加五档难度，影响反应、瞄准误差、转向速度、听声范围、记忆时间、点射节奏与战术协同。队友固定使用老兵配置，不随敌方难度一起变弱。
- AI 具有视野方向与墙体遮挡限制，只会记忆最后观察的位置；听声调查的位置有误差，团队情报经过延迟传递。
- AI 会选择可遮挡敌方视线的掩体，移动到探头位置点射，再撤回掩体。完成几次交火后会重新选择行动；高难度侧翼角色会尝试绕路。
- AI 使用有限弹匣和备用弹药；换弹时停止射击。命中由实际射线和身体/头部碰撞决定，不再是随机扣血。
- 进攻队友从不同路线推进；玩家阵亡后由存活队友接管安放任务。防守方回防时选择一人拆包，其余人分散掩护。
- 枪械从 6 种扩充到 16 种，增加三连发步枪、泵动霰弹枪、轻机枪及多种手枪、冲锋枪和狙击枪。
- 重做独立枪械轮廓、倒角枪身、机匣、导轨、扳机护圈、枪口内孔、螺钉、刻字、握把纹理、弹匣与瞄具。P90 使用顶部弹匣，AK 使用弧形弹匣，M249 有弹链与弹箱，FAMAS/AUG 为无托结构。
- 装备室提供分类浏览和可旋转缩放的真实三维模型。游戏中 F 检视武器，射击时有套筒/枪机运动与抛壳，NOVA 有泵动护木动画。

## 难度

在主菜单或每回合装备室选择；回合进行中不切换。浏览器允许时会记住选择。所有难度使用相同生命、护甲和枪械伤害，主要差别在反应与决策。

| 难度 | 基准反应时间 | 行为说明 |
| --- | --- | --- |
| 新兵 | 1.05 秒 | 反应较慢、点射间隔长，适合熟悉地图与压枪。 |
| 普通 | 0.68 秒 | 听声调查、基础掩体与换弹，保留较多瞄准误差。 |
| 老兵 | 0.43 秒 | 掩体探头、短点射、受伤撤退，分路线推进。 |
| 专家 | 0.28 秒 | 共享已发现的位置，侧翼包抄，回防时分工拆包与掩护。 |
| 噩梦 | 0.18 秒 | 快速反应与稳定点射，积极换位协同；仍受视野、墙体与弹药限制。 |

实际首次射击还受观察间隔、反应浮动、转向、是否对准、弹药和掩体影响。高级 AI 没有隔墙持续追踪玩家坐标的能力。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 上下左右瞄准 |
| 左键 | 射击；自动武器可按住，FAMAS 每次点击三连发 |
| 右键按住 / Q 切换 | 精确瞄准；AWP、SSG 08 和 AUG 打开瞄准镜 |
| R | 使用备用弹药换弹 |
| 1 / 2 或滚轮 | 主武器 / 手枪；切枪取消未完成的三连发与换弹 |
| F | 检视枪械；射击会取消检视 |
| Shift / Ctrl | 静步 / 蹲下 |
| Space | 跳跃，空中散布增大 |
| E 按住 3 秒 | 在 A/B 包点附近静止安放炸弹 |
| Tab 按住 | 战绩与存活状态 |
| Esc | 暂停、调整灵敏度和画质 |
| 装备室拖动模型 / 滚轮 | 旋转 / 缩放预览 |

静止、蹲下、精确瞄准和短点射更精准。连续射击会抬高真实视角并产生横向偏移；向下移动鼠标可以压枪。霰弹枪一次消耗一发霰弹，分别计算八颗弹丸及距离衰减。FAMAS 一次点击发射三发，三发之间也会产生后坐力。

## 回合规则

- 你与四名蓝色标识 AI 队友组成进攻方，对阵五名守军。
- 行动阶段 150 秒，消灭全部守军或成功引爆炸弹即可获胜。
- 炸弹倒计时 40 秒。防守方需要在附近安全地连续拆除 5 秒；更换拆包人会重新计时。
- 安放后即使进攻方全部阵亡，炸弹仍继续倒计时。阵亡后自动观战。
- 初始 $8,000；玩家击杀和安放各奖励 $300；胜局奖励 $3,250，败局奖励 $2,400，资金上限 $16,000。
- 准备阶段没有倒计时催促。存活保留武器，阵亡回到免费 USP-S；每回合补满弹药和生命，护甲补满费用为 $650。
- 没有友军伤害。本版为单机 AI 对抗，尚无联网、换边、投掷物与穿墙弹。

## 地图与画面

以 [Valve 的 Dust II 场景介绍](https://www.counter-strike.net/dust2) 为参考，使用原创程序化几何重建主要路线与沙漠城镇风格。A 点设置 Hotel Aurore、B 点设置 Kasbah 地标；地图尺寸与部分路线经过扩展，不是官方地图或官方资产的 1:1 复刻。

使用真实透视三维场景、日光阴影、距离雾与凹凸材质。人物保留头盔、护目镜、面罩、耳麦、护甲、弹匣袋、手套、护膝、靴子及四肢动作。当前精度仍不等同于商业游戏的人工雕刻、扫描和完整 PBR 资产。旧的 2.5D 版本保存在 legacy/。

## 项目结构与验证

- index.html / style.css：界面、难度选择、装备室和 HUD。
- game.js：输入、实际弹道、音效、回合和模型预览。
- ai.js：感知、记忆、难度配置、战术状态、掩体、包抄、拆包分工。
- weapons.js：16 种枪械模型与可动部件。
- map.js：Dust II 路线、地形高度、建筑、掩体、集中出生点与区域名称。
- level.js：新地图的详细建筑、道具、地形网格及空间分区合并。
- models.js：人物、基础材质和静态几何批次合并。
- core.js：武器参数、地图、碰撞、寻路、后坐力、经济和胜负。
- check.cjs：执行 node check.cjs，运行确定性回归检查。
- vendor/：Three.js 0.160.1，MIT 许可见 THREE-LICENSE.txt。

36 项检查涵盖地图连通、碰撞、实际三维头部命中、难度反应与命中差异、视野遮挡、听声与记忆、掩体和探头、有限弹药、路线推进、情报协同、包抄、拆包分工、FAMAS 三连发、霰弹命中和模型几何有效性，以及五对五出生、高低差通行、隧道遮挡、全部七条 AI 路线、实际移动速度和死亡观战、右键菜单拦截、瞄准输入。无界面检查不验证 GPU 画面、帧率或实际操作手感；另外已用桌面运行环境验证 WebGL 2.0 场景加载、10 名角色、右键和 Q 键瞄准、菜单拦截，并检查出生点截图；尚未完成长时间人工游玩及帧率测试。
