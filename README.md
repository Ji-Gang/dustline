# DUSTLINE 0.10 / 独立网络收发与延迟诊断

## 使用

运行“沙城行动-互联网版.lnk”，或 dist/DUSTLINE-Internet-0.10-win32-x64/DUSTLINE.exe。发送整个 0.10 压缩包给朋友，完整解压后运行。旧程序不会自动更新。

选择“互联网房间（优先玩家直连）”，房主创建并分享 DL3. 开头完整房间码，好友粘贴加入。无需手填 IP、私人路由器或购买服务器。所有玩家请使用 0.10，让双方网络收发都与 3D 渲染分离。

大厅点击蓝／红队 1、2 号空位选择队伍和出生位置，每队最多两人。房主可一人开局；晚加入玩家先选位置，点击“加入战场”，再在出生区选枪。保护从部署时开始；战斗中不能换席位刷新生命。离开不会强制结束剩余玩家的对局，互联网房主关闭软件则结束房间。

## 0.10 延迟优化与诊断

WebRTC 改为独立的隐藏网络页面执行，不再与 3D 游戏页面共享 JavaScript 事件循环；房间关闭时自动释放。此改动针对渲染阻塞引起的收发排队，不改变网络线路本身。双方使用新版时，WebRTC 握手消息增加确认、去重和最多 18 秒重试，恢复偶发丢失的连接请求；不会给实时移动状态启用重传。

右上角第一行仍显示游戏往返延迟；第二行“网络 RTT”来自 WebRTC 当前选中路径的 ICE 统计，“通信 RTT”在主进程收到 ping 回复时计时，不包含随后游戏页面处理显示的等待。三个统计不是同一种测量，不能简单当作同一次测量相减。网络 RTT 很低但游戏延迟高时应排查主机负载和游戏处理；网络 RTT 本身很高时应排查实际链路、拥塞和路由。暂不保证两台实际电脑低于 100ms。

## 0.9 新功能

房主在大厅选择 AI 难度（简单、普通、困难），点击“蓝队 + AI”或“红队 + AI”。AI 占用现有席位，每队最多两人，总计最多四人。开局前可点击“移除 AI”为好友腾位；战斗中不能添加或移除。单人加三个 AI 也能开局，或与朋友一起对抗 AI。

AI 在房主端寻路、感知视野、射击、换弹和重生，与真人使用同一套伤害、掩体、弹药和计分规则。不额外连接外部 AI 服务。

房主确认有效伤害后，准星短暂变为金橙色；爆头命中为红色，开镜时也显示命中标记。击杀后显示骷髅图标与敌人名字，约 1.8 秒后消失。掩体、队友及无敌保护不会触发有效命中提示；获胜的最后一杀也显示图标。

## 这次的联机方式

0.5/0.6 将实时游戏操作和状态发送到公共 MQTT 中转。0.7 使用公共服务交换加密、签名的 WebRTC 建连信息，成功后游戏数据走玩家之间的 WebRTC DataChannel，不再绕公共 MQTT 中转。移动/状态通道不保证顺序且不重传旧包，房间操作/选枪等走可靠通道；房主仍负责命中与计分。双方断开直连时自动退回公共中转。

STUN 使用 Cloudflare 与 Twilio 的公共入口，只帮助发现可达地址。未配置付费 TURN 或专用中转。因此校园网隔离、严格 NAT、防火墙封禁 UDP 时，免费直连仍可能失败。此版不会修改系统防火墙、VPN 或其他游戏。直连会让参赛者的网络端点互相可见，房间码只分享给朋友。

界面显示：
- “玩家直连”：实时数据已建立直接连接；旁边的 ms 是访客到房主的实际游戏 ping。
- “中转连接（未直连）”：仍走旧公共中转，可能有数百毫秒延迟。
- “房主本机 · 直连 n/N”：房主本地运行、哪些访客成功直连；房主本机状态不代表远端延迟。

## 100 ms 目标与验证范围

免费直连有机会消除中转绕路，但没有对你和朋友的网络作 100 ms 保证。双方更新后看访客右上角是否显示“玩家直连”和实际延迟。若仍为中转，不能把本地预测流畅或房主本机低耗时当作网络目标达成。

已用本机四个独立 Electron 客户端验证：真实公共服务交换信令、实际 WebRTC 通道、游戏命令/状态绕过 MQTT、断线回退。测试同机直连约 0–3 ms，退回真实中转为 518 ms。这只证明传输切换有效，不代表跨电脑实测。

0.8 使用固定 60 Hz 输入模拟，约 30 Hz 发包，每包最多补发最近 12 条输入。房主每步最多执行一条命令，执行后确认；客户端据此重放未确认输入。远端与观战使用 50 ms 快照插值。枪声与后坐力本机预测，确认后避免重复播放，伤害仍由房主决定。命中回溯限制在最近 200 ms，不能跨重生，仍检查静态掩体及当前保护。直连拥塞缓解后会重新启用直连。公共房间服务断开目前仍需重建房间，即使曾经直连也不提供无信令服务的房间恢复。

## 0.8 验证

`pvp/netcode-test.cjs` 覆盖输入丢包、乱序、重复、执行确认、移动重放、短点射、重生隔离、插值、命中回溯和拥塞恢复。`desktop/verify-netcode.cjs` 使用实际打包页面，暂不让房主回包，检查本机射击与移动即时反馈。固定 50 ms 插值和最多 200 ms 命中回溯不会降低真实网络 RTT；没有承诺跨电脑低于 100 ms。

参考 fps-netcode 的算法思路自行实现 JS 模块，未复制其 Unity 源码；保留现有 WebRTC，未新增 ENet 或 Valve 原生依赖。
