# 霓虹禁区 / NEON BREACH

离线单人 FPS 小游戏，使用 Canvas 光线投射呈现复古 2.5D 场景，无需安装、联网或下载依赖。

## 启动

双击 `index.html`，使用桌面版 Edge、Chrome 或 Firefox 打开，点击“进入禁区”。允许页面捕获鼠标即可自由转向。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 前后移动、左右平移 |
| 鼠标 | 左右转向瞄准 |
| 鼠标左键（可按住） | 射击 |
| Shift | 冲刺 |
| R | 换弹，备用弹药无限 |
| Esc | 暂停并释放鼠标 |
| 左右方向键 | 备用转向操作 |

击败所有巡逻机后，4 秒后进入下一波。敌人逐波增加，第四波起装甲增强。每四次击杀掉落一个绿色修复模块，走近恢复 30 生命；完成一波恢复 20 生命。右上角小地图显示敌人、补给和障碍物。利用掩体阻挡敌人射击，持续移动寻找射击角度。

这是桌面键鼠游戏，不支持触屏操作。场景采用复古平面转向，没有跳跃或上下视角。音效在首次点击开始后启用。

文件：`index.html`（界面）、`style.css`（样式）、`game.js`（场景、敌人、武器、音效与游戏逻辑）。
